# 0005: 回答確定を単一のサーバー関数へ集約する

- 状態: 採用
- 日付: 2026-07-23

## 決定

公開クライアントへ `answers` の直接INSERT権限を与えない。回答は
`submit_answer(mission_id, choice, photo_path)` RPCだけを通す。

RPCは次を同一処理内で実施する。

- Supabase Anonymous AuthのユーザーIDを `auth.uid()` から取得する。
- ミッションが `public`、`active`、期限内であることを再検証する。
- 回答がミッションの `choices` に含まれることを検証する。
- 写真pathが匿名ユーザーIDとミッションIDの配下であることを検証する。
- `confirmed_at = now()` で回答を作成する。
- ミッションの `reward_miles` と匿名ユーザーの累計マイルを返す。

## 理由

時刻、匿名ID、マイルをクライアント申告にすると改ざんできる。画面側の
検証だけでなく、公開クライアントが迂回できないサーバー境界を作るため。

## 写真失敗時

写真は回答確定前に非公開bucketへアップロードする。RPC失敗時は同じ匿名
ユーザーがそのobjectを削除し、孤立ファイルを残さない。
