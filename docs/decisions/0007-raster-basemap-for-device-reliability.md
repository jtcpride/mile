# 0007: 実機描画を優先してラスター背景地図を使う

- 日付: 2026-07-24
- 状態: 採用

## 背景

GitHub Pagesの静的デモを実機確認したところ、波紋、ズーム、空振り表示は
動作した一方で背景地図が描画されなかった。公開スタイルと京都付近の
OpenFreeMap Vector TileはHTTP 200で配信されていたため、地図を表示しない
仕様ではなく、実機上のVector Tile描画経路の不具合と判断した。

## 判断

MapLibre GL JSは維持し、背景地図をOpenStreetMap Standardのラスタータイルへ
切り替える。追加ライブラリは導入しない。通常の対話表示だけを行い、
プリフェッチやオフライン保存は実装しない。

## 理由

- 外部style、Vector Tile、glyph、spriteの多段取得を1種類の画像タイルに
  単純化し、モバイルブラウザでの再現性を優先する。
- MapLibreの操作、同心円、反応マーカーの実装を変更せずに修正できる。
- ブラウザ標準キャッシュ、Referer、表示中範囲だけの取得という
  OpenStreetMap Tile Usage Policyに沿う。

## 影響

- 地図上にOpenStreetMapの帰属表示を常時表示する。
- 静かな画面トーンに合わせ、MapLibreのraster paintで彩度とコントラストを抑える。
- タイル配信はbest-effortでSLAがない。利用規模が増えた場合は、
  利用規約と費用を確認した別プロバイダーまたは自己ホストへ切り替える。
