# 0002: 現在地をクライアント表示だけに閉じ込める

- 状態: 承認済み
- 日付: 2026-07-23

## 決定

回答者の現在地は、地図の中心合わせと端末内の距離計算にだけ使用する。
現在地や現在地由来の検索範囲を、Supabaseを含む外部サービスへ送信しない。

## 実装上の境界

- `MissionRepository.listActivePublic()` は位置引数を持たない。
- `AnswerSubmission` は `missionId`、`choice`、`photo` だけを持つ。
- DBスキーマに回答者の緯度・経度列を作らない。
- 公開中ミッションを取得後、距離計算と周辺絞り込みを端末内で行う。
- 型、送信ペイロード、SQLスキーマを自動テストする。

## 理由

位置をDBに保存しないだけでなく、アクセスログ等へ位置由来情報が残る
経路も避けるため。v0.1のミッション数が少ない前提では全公開ミッション
取得の負荷は許容できる。

## 将来の見直し条件

公開ミッション数が端末内処理に不適切な規模へ増えた場合は、正確な現在地
を送らない地域タイル方式などを別の設計判断として検討する。
