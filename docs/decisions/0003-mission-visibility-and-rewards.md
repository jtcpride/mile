# 0003: 公開範囲、回答一意性、マイル

- 状態: 承認済み
- 日付: 2026-07-23

## 決定

- 公開面が取得できるのは `visibility = public`、`status = active`、
  `expires_at > now()` をすべて満たすミッションだけとする。
- `visibility = limited` は一覧・詳細とも公開面から取得不能にする。
  v0.1では専用URLやアクセストークンを作らない。
- 同じ匿名利用者は同じミッションへ1回だけ回答できる。DB一意制約を
  最終防衛線とする。
- `missions.reward_miles` を追加する。初期運用のseedは全件同値とする。
- 公開面に回答数、達成率、他者の回答を表示しない。

## 理由

表示側だけのフィルターでは、URL直打ちやAPI直接呼び出しで非公開情報が
漏れる可能性がある。RLSとサーバー関数で公開条件、期限、選択肢、一意性を
検証する。
